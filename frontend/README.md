# Frontend — Vue 3 SPA (Vite)

Isolated Node project. Nothing here depends on the `backend` folder.
It only talks to the backend over HTTP, using `VITE_API_BASE_URL`.

## Setup (to be done in a later step)

1. Scaffold the Vite + Vue 3 project inside this folder.
2. Install dependencies via npm.
3. Copy `.env.example` to `.env`.
4. Start the dev server.
